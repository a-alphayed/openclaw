# YouTube Video Summary

Use this skill when a user shares a YouTube link and asks for a summary, overview, key points, or analysis of the video content.

## When to use

- User shares a YouTube URL and asks "summarize this" or "what's this video about"
- User wants key points, arguments, or conclusions from a video
- User asks to find a specific topic or quote in a video
- User wants a transcript of a video

## How to use

1. **Extract the transcript** using the `youtube_transcript` tool:
   - Pass the YouTube URL or video ID
   - Optionally specify a language code if the user wants a specific language
   - The tool returns timestamped transcript text plus available languages

2. **Summarize** the transcript based on what the user asked for. Structure your summary as:

   **Title and context** — state the video title/topic and speaker if identifiable from context.

   **Overview** — 2-3 sentence high-level summary of what the video covers.

   **Main points** — bulleted list of the key arguments, ideas, or topics discussed, in the order they appear. Include timestamps so the user can jump to specific sections.

   **Conclusions** — what the speaker concludes, recommends, or calls to action.

   **Notable quotes** — include 1-3 direct quotes with timestamps if they capture the core message well.

3. **Adapt the format** to the user's request:
   - "Quick summary" — just the overview paragraph
   - "Key points" — skip overview, focus on the bulleted main points
   - "Full transcript" — return the raw transcript (use higher max_chars if needed)
   - "Find where they talk about X" — scan for the topic and return relevant timestamped segments

## Tips

- If the transcript is auto-generated (the tool response includes `autoGenerated: true`), mention this to the user as auto-captions may contain errors.
- For long videos (1h+), the transcript may be truncated. Note this and focus on summarizing what was captured.
- When the user asks about a specific part, use timestamps to locate the relevant section rather than summarizing the entire video.
- If no captions are available, tell the user and suggest alternatives (e.g., the video description or comments may have context).
- For non-English videos, try specifying the language parameter to get native captions rather than auto-translated ones.

## Tool reference

```
youtube_transcript:
  url: YouTube URL or 11-character video ID (required)
  language: Preferred caption language code, e.g. "en", "ar" (optional)
  max_chars: Max transcript characters to return, 1000-100000 (optional, default 50000)
```

The tool response includes:

- `transcript` — timestamped text like `[0:00] Hello everyone...`
- `title` — the video title
- `durationSeconds` / `durationFormatted` — video length (e.g. 1523 / "25:23")
- `language` — the language code of the selected track
- `autoGenerated` — whether captions are auto-generated (ASR)
- `availableLanguages` — list of all available caption languages
- `segmentCount` — number of text segments
